# 🇩🇪 Germany 2026 World Cup Kader Builder

A single-file web app to build your predicted Germany squad for the **2026 FIFA World Cup** (USA · Canada · Mexico).

**[→ Open App](https://moergenicebach.github.io/Kader2026/)**

---

## Features

- **56 players** — all realistic Germany candidates, grouped by position (GK / DEF / MID / FWD)
- **Drag & drop** — build your 29-man squad from the player pool
- **Starting XI** — pick your 4-2-3-1 lineup from your squad
- **Club logos** — automatic logos for all clubs via football-data.org
- **Export** — download your Kader as PNG or PDF
- **No install, no backend** — single HTML file, works offline

## Usage

Just open `index.html` in any browser. No server or installation needed.

Or use the hosted version via GitHub Pages.

## Stack

- Vanilla HTML / CSS / JavaScript
- [SortableJS](https://sortablejs.github.io/Sortable/) — drag & drop
- [html2canvas](https://html2canvas.hertzen.com/) — PNG export
- [jsPDF](https://github.com/parallax/jsPDF) — PDF export
- [football-data.org](https://www.football-data.org/) — club crests CDN

## How to share

Send `index.html` directly, or host it anywhere (GitHub Pages, Netlify Drop, etc.).
